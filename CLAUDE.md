## Project

Arcade Vault: a planned platform for playing games online and competing on a points leaderboard (see README.md). The repository is currently the unmodified output of `create-next-app` (App Router, TypeScript, Tailwind CSS v4) — `app/page.tsx` and `app/layout.tsx` still contain the default starter content, so no product architecture exists yet.

## Commands

```bash
npm run dev      # start dev server (Next.js, Turbopack)
npm run build    # production build
npm run start    # run production build
npm run lint     # eslint (flat config, eslint.config.mjs)
```

There is no test runner configured yet.

## Before writing code

Read `node_modules/next/dist/docs/` first — this project pins Next.js 16.3.3, which has breaking changes vs. older Next.js versions likely present in training data (e.g. typed route props like `LayoutProps<"/">` in `app/layout.tsx`). See AGENTS.md above for details; that block is regenerated by `next dev` and should be committed as-is, not stripped out.

## Workflow
