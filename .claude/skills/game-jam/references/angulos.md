# Ángulos de la game jam

Los tres diseñadores reciben el mismo tema y un ángulo distinto. El ángulo fija el tipo de juego para que las tres propuestas no converjan en la misma idea.

## A — Acción arcade

- Categoría preferida: `ARCADE` o `SHOOTER`.
- Reflejos y movimiento constante; partidas de 1–5 minutos; dificultad que sube con el tiempo.
- Pregunta guía: "¿Qué se esquiva, se atrapa o se dispara en este tema?"

## B — Puzzle / estrategia

- Categoría preferida: `PUZZLE`.
- Combinar, ordenar, encajar o gestionar recursos **bajo presión de tiempo** (para que el score sea arcade y no solo "resuelto/no resuelto").
- Pregunta guía: "¿Qué se organiza, se mezcla o se optimiza en este tema?"

## C — Wildcard / versus

- Categoría preferida: `VERSUS` contra CPU, o cualquier categoría con una mecánica inesperada (un botón, física, ritmo, gestión).
- Prioriza las categorías y colores con menos juegos jugables (ver `references/implemented-games/implemented-games.md`).
- Pregunta guía: "¿Qué enfrentamiento o giro sorprendente esconde este tema?"

## Reglas de diversidad

- Cada propuesta debe diferir de las otras en **mecánica núcleo** y en al menos uno de: categoría o color.
- `id` único: ni del catálogo, ni de la memoria de game-planner, ni de las otras propuestas. Si dudas de colisión, añade un sufijo temático (`-expreso`, `-tueste`).
- Si el tema encaja mal con tu ángulo, adáptalo con creatividad; no cambies de ángulo.
